# @zeldrisho/pi-cloudflare

> **Deprecated:** This package is now a no-op. Unconditional system-prompt guidance is less useful than guidance scoped to the project or task.

Use the canonical [`create-cloudflare` agent guidance](https://github.com/cloudflare/workers-sdk/blob/main/packages/create-cloudflare/src/agents-md.ts) as the source for a project `AGENTS.md` or referenced documentation. For larger, conditional workflows, use a skill that retrieves current Cloudflare documentation only when needed.

## Remove

```bash
pi remove npm:@zeldrisho/pi-cloudflare
```

For a project-local installation:

```bash
pi remove -l npm:@zeldrisho/pi-cloudflare
```
