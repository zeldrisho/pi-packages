All notable changes to this project will be documented in this file.

## [Unreleased]

## [0.1.2] - 2026-10-04

### Changed

- Hardened CodeRabbit review authentication guidance and bounded sandbox recovery.
- Preserve reported autofix finding severities and assess actionability independently.

## [0.1.1] - 2026-09-28

### Changed

- Removed redundant repository-instructions loading from the `autofix` workflow.

## [0.1.0] - 2026-09-28

### Added

- CodeRabbit `autofix` and `code-review` skills adapted for explicit invocation in Pi.

### Changed

- Hardened autofix review-thread error handling and clarified manual invocation and authentication guidance for CodeRabbit reviews.
