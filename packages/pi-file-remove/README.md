# @zeldrisho/pi-file-remove

> **Deprecated:** This package is now a no-op. File-removal preferences should be scoped through context files instead of appended to every system prompt.

Move the `gomi` preference into your user or project `AGENTS.md`, including any environment-specific exceptions for CI, containers, or production.

## Remove

```bash
pi remove npm:@zeldrisho/pi-file-remove
```

For a project-local installation:

```bash
pi remove -l npm:@zeldrisho/pi-file-remove
```
